# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind and specific. Review packs, code and ideas, not people. Assume the other person is learning, because here everyone is. Harassment, personal attacks and discrimination of any kind are not accepted in issues, pull requests, discussions or anywhere the project meets.

If something happened that should not have, write to the maintainer through the contact in the GitHub profile. Reports are read by one person and handled privately.
