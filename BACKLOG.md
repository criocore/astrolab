# Backlog

Решения, принятые 22.10.2026 и снятые с этого списка: лицензия кода MIT (тексты пакета CC BY-SA 4.0); публичный пакет без roadmap.sh (ни текстов, ни ссылок, письмо автору не нужно); порядок тем внутри эпохи свободный, замок только на вратах; рубрика экзамена = `checks` грейда из пакета, цитата проверяется по файлу.

## Механика (после v0.1)
- Эврика как дело в папке ученика: у темы ядра одно дело (шаблон пути + строка, которую должен содержать файл, или команда и строка в её выводе); пройденное дело заполняет один сегмент кольца навсегда, остальные сегменты закрывает устная проверка. Спецификация: файл ревью механики от 21.10 (обзор механики от 21.10).
- Настоящие предпосылки как данные пакета (`requires` у темы): читают и сервер (замок), и дерево (стрелки). Сейчас сервер открывает всю эпоху после врат предыдущей, дерево рисует то же.
- Альтернативные темы внутри эпохи: врата называют, какие ветки обязательны.
- Привязка уровня смежной области к конкретной теме, когда он её меняет (например Р8 секреты → G2 хук-страж); остальные уровни необязательны.
- Проверка уровня смежной области по короткой рубрике `checks`, как у врат (сейчас по критериям тем уровня).

## Интерфейс
- Хроника как автоматическая лента событий по дням (проверки, зажжённые звёзды, врата, разговоры, заметки); учёт времени ручной.
- Лоция: решения (ADR с тремя вариантами), пробы, инструменты; хранить файлами в папке ученика (`docs/adr/…`), которые читает экзамен. Старые формы радара и ADR в базе снять.
- Мобильная вёрстка проверена только по коду.
- Онбординг: список моделей Codex (сейчас только свободное поле) и Gemini (имена из бандла 0.56, не проверены на доступность); флаг усилия для Gemini появится, если CLI его добавит.
- Журнал рабочего места: строка «агент отвечает» должна загораться и после первой настоящей проверки темы, не только по кнопке; результат кнопки хранить в data (сейчас только в памяти вкладки).
- Онбординг, шаг 2: кнопка «Проверить вызов» сделана в журнале эры I, на сам экран онбординга не вынесена; (один короткий check-вызов по явному клику, показывает «не залогинен»/лимит), поле «свой CLI» (путь + пресет) прямо на экране, «Без агента, демо».
- Корешки эпох: длинные английские названия грейдов обрезаются многоточием; подобрать перенос или короткие заголовки в пакете.
- Таймер времени на тему.

## Движок и дистрибуция
- MCP-сервер хаба: агент читает программу и прогресс, предлагает отметки (подтверждение в хабе).
- Адаптер opencode. Факты на 22.10.2026 по opencode.ai/docs/cli: `opencode run [message..] --format json --agent <name> --dir <path>`, промпт только позиционным аргументом (stdin не документирован; на Windows через .cmd это лимит 8 КБ командной строки), события json: `step_start`, `tool_use` (part.tool, part.state.input/output), `text` (part.text), `step_finish` (part.tokens, part.cost), `error`; «только чтение» через агента в конфиге с `permission: {edit: deny, shell: deny, webfetch: deny}` (inline-конфиг `OPENCODE_CONFIG_CONTENT`). Формат событий виден только у третьих лиц, нужен живой прогон перед пресетом.
- Живой прогон Codex CLI и Gemini CLI (пресеты написаны по документации 22.10, аккаунтов нет; у Gemini бесплатный тариф с 18.06.2026 переехал в Antigravity, CLI отвечает кодом 41/55). Для Codex: продолжение разговора (`codex exec resume <id>`) и отключение MCP-серверов пользователя; для Gemini: файл политики, чтобы выключить google_web_search на экзамене.
- Формат пакетов YAML.
- Установка одной командой (npx), релизы, скриншоты для README.
- Чат наставника не пишется в `data/logs/mentor.jsonl` (только проверки и экзамены).
- Ежемесячная проверка ссылок пакета в CI, шаблон issue «ссылка умерла».
